¿Errores de límite de peticiones? Pega un token gratuito (opcional)

Sin token: 60 peticiones/hora. Con un token de solo lectura gratuito: 5000/hora. Genera uno en github.com/settings/tokens (no necesita ningún permiso marcado, es solo para leer datos públicos) y pégalo aquí. Se queda solo en tu navegador — nunca se manda a ningún servidor nuestro, solo directo a la API de GitHub.

Nota: estas estadísticas reflejan la actividad en los repositorios propios del usuario (commits, lenguajes, estrellas). No incluyen contribuciones a repositorios de otras personas u organizaciones — la API pública de GitHub no permite calcular eso de forma confiable sin autenticación.
